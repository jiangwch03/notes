## 1 简介

Markdown 是一种轻量级标记语言，常见用途包括博文、电子书、README，以及大模型输出。

- 高效排版，速度快，样式尚可
- 易读、易写、易学
- 跟 HTML 类似，但更简单
- 兼容基本 HTML 标签
- 崇尚极简主义

## 3 文本格式

### 3.1 标题

Markdown 支持 6 级标题，`#` 数量对应级别。

**语法：**

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

**效果：**（用表格示意字号，避免打乱本文目录）

| 级别 | 效果示意 |
| :-- | :-- |
| 一级 | <span style="font-size:2em;font-weight:700">一级标题</span> |
| 二级 | <span style="font-size:1.6em;font-weight:700">二级标题</span> |
| 三级 | <span style="font-size:1.35em;font-weight:700">三级标题</span> |
| 四级 | <span style="font-size:1.15em;font-weight:700">四级标题</span> |
| 五级 | <span style="font-size:1em;font-weight:700">五级标题</span> |
| 六级 | <span style="font-size:0.9em;font-weight:700;color:#666">六级标题</span> |

### 3.2 分割线

三个 `*` 或三个下划线。

**语法：**

```markdown
***
___
```

**效果：**

***

### 3.3 强调

文字前后 1 个 `_` / `*` 为倾斜，2 个为加粗，3 个为加粗斜体。

中文斜体往往不明显：多数中文字体没有独立斜体字形，预览只是把汉字稍微倾斜，和正体几乎一样。加粗依赖字体字重，有的主题里对比也不大。英文、数字会清楚很多。

**语法：**

```markdown
倾斜：*italic* 对比 *白胡椒粉* 和 白胡椒粉
加粗：**bold** 对比 **白胡椒粉** 和 白胡椒粉
加粗斜体：***bold italic*** 对比 ***白胡椒粉*** 和 白胡椒粉
```

**效果：**

倾斜：*italic* 对比 *白胡椒粉* 和 白胡椒粉

加粗：**bold** 对比 **白胡椒粉** 和 白胡椒粉

加粗斜体：***bold italic*** 对比 ***白胡椒粉*** 和 白胡椒粉

`_` 和 `*` 效果相同，下面不再重复两套写法。

### 3.4 下划线与删除线

下划线没有原生语法，用 HTML `<u>`。删除线用前后两个 `~~`（Esc 下方按键，需配合 Shift）。

**语法：**

```markdown
下划线 <u>白胡椒粉</u>
删除线 ~~删除~~
```

**效果：**

下划线 <u>白胡椒粉</u>

删除线 ~~删除~~

## 4 列表

### 4.1 无序列表

`-` 加空格是一级列表；下级用 Tab 缩进后再写 `-` 加空格。`-` 也可用 `+` 替代。预览时不同层级的项目符号可能不同（实心圆、空心圆、方块），取决于编辑器。

**语法：**

```markdown
- 一级列表1
    - 二级列表1
        - 三级列表1
            - 四级列表1
- 一级列表2
- 一级列表3

+ 一级列表1
    + 二级列表1
        - 三级列表1
            - 四级列表1
+ 一级列表2
+ 一级列表3
```

**效果：**

- 一级列表1
    - 二级列表1
        - 三级列表1
            - 四级列表1
- 一级列表2
- 一级列表3

+ 一级列表1
    + 二级列表1
        - 三级列表1
            - 四级列表1
+ 一级列表2
+ 一级列表3

### 4.2 有序列表

数字加 `.` 再加空格。嵌套同样用缩进。源码里每一级都可以写成 `1.`，预览里会按层级换成 `1.` / `i.` / `a.` 等样式。

**语法：**

```markdown
1. 一级列表1
    1. 二级列表1
        1. 三级列表1
2. 一级列表2
3. 一级列表3
```

**效果：**

1. 一级列表1
    1. 二级列表1
        1. 三级列表1
2. 一级列表2
3. 一级列表3

## 5 链接与图片

### 5.1 超链接

可加提示文字（鼠标悬停显示 title）。

**语法：**

```markdown
<!-- 超级链接 -->
[百度](https://baidu.com)
[百度](https://baidu.com "百度一下，你就知道")
[京东](https://jd.com)
```

**效果：**

[百度](https://baidu.com)

[百度](https://baidu.com "百度一下，你就知道")

[京东](https://jd.com)

### 5.2 图像

写法是 `![替代文字](图片路径 "悬停提示")`。路径指向本地文件或网络地址。设置宽高等要用 HTML `<img>`。

同目录已放 `img1.png`、`img2.png`。

**语法：**

```markdown
<!-- 加载图像 -->
![Markdown](./img1.png)
![Markdown](./img1.png "这是一个 Markdown Logo")
![示例图2](./img2.png)
```

```html
<img src="./img2.png" alt="示例图2" width="200" />
```

**效果：**

![Markdown](./img1.png "这是一个 Markdown Logo")

![示例图2](./img2.png)

用 HTML 限制宽度为 200：

<img src="./img2.png" alt="示例图2" width="200" />

## 6 表格

对齐：`-` 左边加 `:` 左对齐，右边加 `:` 右对齐，两边都加则居中。部分 IDEA 版本对对齐写法识别不稳定。

**语法：**

```markdown
| 姓名 | 年龄 | 性别 | 爱好 |
| :- | :- | :- | :- |
| 张三 | 80 | 男 | 无 |

| 左对齐 | 居中 | 右对齐 |
| :----- | :---: | -----: |
| A | B | C |
```

**效果：**

| 姓名 | 年龄 | 性别 | 爱好 |
| :- | :- | :- | :- |
| 张三 | 80 | 男 | 无 |

| 左对齐 | 居中 | 右对齐 |
| :----- | :---: | -----: |
| A | B | C |

## 8 数学公式

行内用 `$...$`，独立用 `$$...$$`。部分渲染器也认 `\infin`，标准写法是 `\infty`。

### 8.1 基本格式

**语法：**

```markdown
这是爱因斯坦的质能方程 $E=MC^2$

$$ E=MC^2 $$
```

**效果：**

这是爱因斯坦的质能方程 $E=MC^2$

$$ E=MC^2 $$

### 8.2 角标

`^` 上标，`_` 下标，多字符用 `{}`。

**语法：**

```markdown
- $y=x^2$
- $y=x^{n+2}$
- $y=2x_1-0.5x_2+3$
- $y=x_{n-1} + x_{n-2}$
```

**效果：**

- $y=x^2$
- $y=x^{n+2}$
- $y=2x_1-0.5x_2+3$
- $y=x_{n-1} + x_{n-2}$

### 8.3 分数

`\frac{分子}{分母}`

**语法：**

```markdown
- $x=\frac{1}{2}$
- $y=\frac{x^2 + 1}{x_1+x_2-6}$
```

**效果：**

- $x=\frac{1}{2}$
- $y=\frac{x^2 + 1}{x_1+x_2-6}$

### 8.4 累加与累乘

**语法：**

```markdown
- $\sum{x_i}$
- $\sum_{i=0}^{N}{x_i}$
- $\prod{x_i}$
- $\prod_{i=0}^{N}{x_i}$
```

**效果：**

- $\sum{x_i}$
- $\sum_{i=0}^{N}{x_i}$
- $\prod{x_i}$
- $\prod_{i=0}^{N}{x_i}$

### 8.5 开方

**语法：**

```markdown
- $\sqrt{2}$
- $\sqrt[n]{x_1}$
```

**效果：**

- $\sqrt{2}$
- $\sqrt[n]{x_1}$

### 8.6 积分与无穷

**语法：**

```markdown
- $\int{f(x)dx}$
- $\int_0^1{f(x)dx}$
- $+\infty$
- $-\infty$
- $\int_{-\infty}^{+\infty}{f(x)dx}$
```

**效果：**

- $\int{f(x)dx}$
- $\int_0^1{f(x)dx}$
- $+\infty$
- $-\infty$
- $\int_{-\infty}^{+\infty}{f(x)dx}$

### 8.7 极限

**语法：**

```markdown
- $\lim{\frac{1}{n}}$
- $\lim_{n \to +\infty} {\frac{1}{n}}$
```

**效果：**

- $\lim{\frac{1}{n}}$
- $\lim_{n \to +\infty} {\frac{1}{n}}$

### 8.8 对数

**语法：**

```markdown
- $\log_{10}x$
- $\log_2{(x^2+1)}$
- $\ln(x_1 + 2)$
```

**效果：**

- $\log_{10}x$
- $\log_2{(x^2+1)}$
- $\ln(x_1 + 2)$

### 8.9 矩阵

也可用 `pmatrix`、`bmatrix` 等环境加括号。

**语法：**

```markdown
$$
\begin{matrix}
1 & 2 \\
3 & 4
\end{matrix}
$$
```

**效果：**

$$
\begin{matrix}
1 & 2 \\
3 & 4
\end{matrix}
$$
